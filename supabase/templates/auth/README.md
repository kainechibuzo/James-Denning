# Supabase Auth — Invite User email

**Template subject:** You're invited to James-Denning — accept & create your password

**Template location:** Supabase Dashboard → Authentication → Email Templates → Invite user

**Sender:** James-Denning <accounts@james-denning.com.ng>

Paste the contents of [invite-user.html](./invite-user.html) into the Invite user template body. Keep the Supabase-generated `{{ .ConfirmationURL }}` placeholder unchanged: it is the secure invitation/verification link generated by Supabase Auth.

The message explicitly tells the recipient to accept the invitation, verify their email, and create a password before signing in. Do not replace this with a manually generated Resend link or send a password in email.

## Activation flow

1. Workspace administrator invites the user through Supabase Auth.
2. Supabase sends this Invite user email.
3. Recipient clicks **Accept invitation & create password**.
4. The application opens its password-setup route, requires a password and confirmation, and calls `supabase.auth.updateUser({ password })`.
5. The application loads the authenticated profile and workspace.

## Important

This file is the source-controlled template. It does **not** automatically change the live Supabase Auth template. After applying it in the Supabase Dashboard, send a fresh invitation to verify the rendered email and full activation flow.
